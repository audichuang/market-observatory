I run a personal US-equity dashboard. Its forecasting component estimates, for the S&P 500 PRICE index (USD, no dividends):
  (a) P(up): probability the close 21 trading days from now is above today's close;
  (b) P(dd5): probability that any close in the next 21 trading days is ≥5% below today's close.

Current model (deliberately minimal):
- Base rates use 1990-01-02 onward, expanding window (P(up) base ≈ 64%, P(dd5) base ≈ 16.6%). The output falls back to the base rate when no condition qualifies; otherwise it is the shrunk conditional probability described below.
- Only two binary conditions: close above its 200-day SMA; VIX ≥ 30.
- Conditional probability is shrunk toward the base rate: p = (40·p_base + n·p_cond)/(40 + n), n = effective sample = days/21; a condition needs nEff ≥ 30 and ≥ 8 separate episodes (episodes ≥21 trading days apart).
- Validation: non-overlapping 21-day walk-forward (~416 rows since 1992), Brier skill score vs. base rate, averaged over 21 start phases, stationary block bootstrap CIs, and a data-snooping null threshold from 20 block-permuted label series.
- Result so far: P(up) shows NO detectable skill (BSS ≈ 0.001 [−0.007, 0.009]). P(dd5) DOES: BSS ≈ 0.049 [0.016, 0.083].
