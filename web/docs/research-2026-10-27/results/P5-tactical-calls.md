### 此目錄能支持的評分範圍

本次選樣以**找到當時發布證據**為準，沒有依事後 SPX 表現挑選。官方 archive、方向相反的 calls、撤回、區間預測及不方便二元化的語句都予以保留。不過，公開媒體與可讀 archive 本身仍是經過選擇的樣本。

你本地建檔時，至少應把下列欄位與原文一起保存：

- `public_date/time` 與 `note_date/as_of_date`；
- `new_call / reiteration / reversal / withdrawal`；
- `SPX / broad_US / global_equities / sector_or_factor`；
- `unconditional / conditional / path / range / observation`；
- 原述 horizon，以及你另行施加的評分 horizon；
- 原稿、原稿副本、二手引語、官方標題／前言等存取狀態。

尤其是**「修正可能發生」「先回測再買」「全球股票 overweight」「月底上漲」**，各自對應不同命題。它們可以保留在同一份事件資料庫，但不能不經事先編碼規則，就全部當成「發布當日起，固定交易日後 SPX 收盤上或下」的同質預測。這份目錄首先能檢驗的是**這批可見、可追溯的公開 calls**；對策略師全部研究產出的技能，仍須保留選樣限制。
