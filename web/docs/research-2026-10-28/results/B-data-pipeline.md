## 五、單點故障、容量與降級

### 已確認的容量缺口：Budget 尚餘很多，也可能 D1 先失敗

Cloudflare D1 官方 [Limits](https://developers.cloudflare.com/d1/platform/limits/)（頁面更新 **2026-10-24**，本輪 **2026-10-28**查閱）列：每查詢最多 **100 bound parameters**；Paid 單庫 **10 GB**；每 invocation **1000 queries**。同頁另明確寫 `batch()` 對 invocation query count 算一次，而每個 statement 仍受個別 SQL／參數限制。這點與 [web/src/server/jobs.ts:295](https://github.com/audichuang/market-observatory/blob/99066fd3ad63ec7b040f6fd447f255b2d3c3964a/web/src/server/jobs.ts#L295) 的舊註解「每句都算 invocation 查詢」不完全一致，不能只拿註解當平台規格。
